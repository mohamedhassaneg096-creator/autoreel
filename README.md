# Reel Studio v1 — استوديو الريلز العلمية «عارف ليه؟»

تطبيق ويب محلي يحوّل أي موضوع علمي إلى فيديو رأسي جاهز (**1080×1920**) بالعامية المصرية وبأسلوب الرسوم التقنية الداكنة، بدون أي خوادم خارجية غير واجهات الـ API المحددة.

## المتطلبات
- **Node.js 18+** (ES Modules، خادم `node:http` مباشر على `127.0.0.1:4301`).
- **FFmpeg** متاح في `PATH`.
- **Chromium** (يُثبّت تلقائياً عبر Playwright أو يستخدم متصفح Chrome المثبت على النظام).

## التثبيت والتشغيل السريع
1. التثبيت لأول مرة:
   ```bash
   npm run setup
   ```
2. تشغيل التطبيق محلياً:
   ```bash
   npm start
   ```
   ثم افتح المتصفح على: `http://127.0.0.1:4301`
   *(على نظام ويندوز يكفي الضغط المزدوج على `start.bat`)*.

## الإعدادات ومفاتيح الـ API
يمكنك تعديل الروابط والمفاتيح ومجلد الخطوط العربية من شاشة **الإعدادات** داخل الواجهة (تُحفظ في `data/settings.json` وتُعرض مقنّعة بآخر ٤ أحرف فقط) أو عبر ملف `.env` (انظر `.env.example`):
- **LLM (FreeLLMAPI أو أي مزود متوافق مع OpenAI)**: افتراضياً `http://127.0.0.1:31415/v1` والموديل `auto`.
- **Voice (ElevenLabs)**: توليد الصوت مع توقيت كل حرف، مع إمكانية رفع ملف صوتي خاص بك.
- **Timing (Deepgram nova-3)**: استخراج توقيت الكلمات عند رفع صوت مخصص، مع محاذاة **LCS** على حروف السكريبت.
- **الخطوط**: خط **IBM Plex Sans Arabic** مدمج في `assets/fonts` مع ملف الترخيص `OFL.txt`، ويمكن تغيير مجلد الخط من الإعدادات.

## مراحل الإنتاج (5 مراحل)
1. **السكريبت (`script`)**: توليد سكريبت مصري قصير بمعدل ~٢.٦ كلمة/ثانية وفق دليل `references/script-style.md`.
2. **الصوت (`voice`)**: توليد التعليق عبر ElevenLabs أو رفع ملف صوتي.
3. **التوقيت (`timing`)**: محاذاة الكلمات عبر LCS مع تمييز الكلمات الضعيفة وإتاحة تعديلها.
4. **الستوري بورد (`storyboard`)**: بناء المشاهد (٩ قوالب رسم) مع مراجعة ذاتية ثانية وإصلاح تلقائي وربط الأيقونات المحلية.
5. **الريندر (`render`)**: تصوير حتمي عبر Playwright بمعدل 30 إطار/ثانية وترميز FFmpeg H.264 مع تطبيع صوتي **−14 LUFS**.

## الاختبار دون اتصال بالإنترنت (Mock APIs & E2E)
```bash
npm run test:e2e
```
يشغّل هذا الأمر الخادم الوهمي `tools/mock-apis.mjs` على المنفذ `:4399` وينتج فيديو تجريبياً مدته 10 ثوانٍ بالكامل.
